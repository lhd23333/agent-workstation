# agent 工作站

集中管理所有 agent 监控面板的本地工作台。

**当前状态：v0（2026-10-06）——只有面板契约与登记表，没写一行代码。**
这是有意为之：先把"每块面板长什么样"固定下来（契约先行），等真需要聚合时再动手（触发条件见路线图）。

## 面板契约

每块面板用一个 JSON 条目登记（见 `panels.json`）：

| 字段 | 含义 |
|---|---|
| `name` | 面板名称（给人看） |
| `kind` | 形态：`web`（常驻服务）/ `file`（静态状态文件） |
| `repo` | 面板所属仓库根目录（绝对路径） |
| `data_dir` | 数据目录（md/json 真相所在，相对 repo） |
| `url` / `port` | web 类的访问入口 |
| `start` / `stop` | 启停命令（相对 repo） |
| `health` | 状态检查（URL 或文件路径） |
| `notes` | 备注（规范、桥接、版本等） |

**协同前提（硬约定）**：面板的真相必须落在 md/json 文件里，工作站不藏任何私有状态——
任何 agent（claude / codex / pi）不经过工作站也能直接读写面板数据。
